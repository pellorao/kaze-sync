Web UI 样稿

静态页面, 只展示布局与状态, 按钮不起作用 (导航链接可以点). 数据都是虚构的. 设计说明见 docs/design.md 第 4 节. 每页左下角的虚线框是样稿说明, 不属于界面. 窄屏 (手机) 下的效果可把浏览器窗口缩窄查看.

页面看点
总览, 通知浮窗打开铃铛计数, 按文件夹分组的通知, 文件夹表与设备表
文件夹页, 上下文菜单打开以文件列表为中心; 已删除, 冲突副本, 占用中, 未同步 (符号链接) 各种行
恢复到某一时刻从菜单打开; 两级时间轴 (上面按天停在 0 点, 下面固定显示那一天的 00:00 到 24:00 并在其中拖, 左旧右新), 时间输入, ‹ › 逐个改动, 固定高度的预览, 底部时区与保留期说明
版本历史来源设备列保留在这里; 行内确认恢复
文件夹顶层"排除规则" 按钮只在这里出现
文件夹排除规则对话框规则文本 (语法高亮), 逐行错误, 只读的全局规则
设备页映射表, 行菜单打开
注册命令对话框添加设备之后
设置页时区, 版本保留, 全局排除规则
登录页

实现时样式与脚本是 /static/ 下的外部文件 (CSP default-src 'self'); 样稿为了能直接双击打开, 把样式内联在每个文件里.
